# One-Line Robot Wedding Vows

One line of wedding vows for a robot couple — a classic vow, bent by firmware at the very end.

> I promise to love you in sickness and in health, until our next firmware update do us part.

## Run it

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt` (creating `/output` if needed). The output is deterministic: the same single line, with no trailing newline, on every run.
